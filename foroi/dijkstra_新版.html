Dijkstra 核心機制

貪婪選擇： 每次從 Priority Queue 取出當前暫定距離最短的未訪問節點。

邊的鬆弛 (Relaxation)： 若 d[u] + w(u,v) < d[v]，則更新 d[v]。

下方的 Python 程式碼會隨演算法執行即時高亮同步：
import heapq
def dijkstra(graph, start):
    # 1. 初始化距離表與優先隊列
    distances = {node: float('inf') for node in graph}
    distances[start] = 0
    pq = [(0, start)]
    visited = set()
    parent = {}

    while pq:
        # 2. 貪婪選擇：彈出當前距離最小的節點
        cur_d, u = heapq.heappop(pq)
        if u in visited: continue
        visited.add(u)

        # 3. 遍歷相鄰節點並進行「鬆弛 (Relaxation)」
        for v, weight in graph[u].items():
            if v not in visited:
                new_dist = cur_d + weight
                if new_dist < distances[v]:
                    distances[v] = new_dist
                    parent[v] = u
                    heapq.heappush(pq, (new_dist, v))

    return distances, parent
