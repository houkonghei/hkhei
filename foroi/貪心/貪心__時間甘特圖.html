貪心關鍵：按結束時間 ($f_i$) 升序排序，優先選擇結束得最早的活動，為後續活動留下最多時間！

貪心算法的核心理論與證明

活動選擇問題（Activity Selection Problem）目標是在共享同一資源的 $n$ 個活動中，挑選出互不相交（Compatible）的最大活動個數。 數學上，每個活動 $i$ 有半開區間 $[s_i, f_i)$。若活動 $i$ 與 $j$ 滿足 $s_i \ge f_j$ 或 $s_j \ge f_i$，則稱兩者相容。

正確策略：最早結束時間 (Earliest Finish Time)

為什麼「按結束時間升序排序」最優？

直觀直覺（Intuition）： 當我們選擇一個結束時間最早的活動時，該活動所佔用的時間資源最快釋放，從而為「剩餘未安排的活動」留下最多的時間空間（Rest Space）。

【數學證明概要：Greedy Stays Ahead】

假設最優解為 $O = \{o_1, o_2, \dots, o_m\}$，貪心解為 $A = \{a_1, a_2, \dots, a_k\}$。

我們可以用數學歸納法證明，對任意 $r \le k$，都有 $f(a_r) \le f(o_r)$。

因為 $f(a_1)$ 是所有活動中最早結束的，所以 $f(a_1) \le f(o_1)$。若將 $o_1$ 替換為 $a_1$，新集合依然相容且數量相同。以此類推，貪心解數量 $k \ge m$，故貪心解即為最優解！

時間複雜度: $O(n \log n)$ (排序為主導) 空間複雜度: $O(1)$ 或 $O(n)$

常見直覺「錯誤貪心策略」反例解析

❌ 錯誤策略 1：按「最早開始時間 ($s_i$)」排序

反例： 活動 A=[1, 10]，活動 B=[2, 3]，活動 C=[4, 5]。

貪心選擇 A=[1,10] → 只能選 1 個
最佳解答 選 B=[2,3] + C=[4,5] → 可選 2 個！
❌ 錯誤策略 2：按「最短持續時間 ($f_i - s_i$)」排序

反例： 活動 A=[1, 5]，活動 B=[4, 6] (長度2)，活動 C=[5, 9]。

貪心選擇 B=[4,6] → 阻礙了 A 與 C，只能選 1 個
最佳解答 選 A=[1,5] + C=[5,9] → 可選 2 個！
❌ 錯誤策略 3：按「最少重疊衝突次數」排序

存在特製構造圖，選擇最少衝突者同樣會導致割裂時間軸，無法保證全域最優。

標準 C++ 滿分解答 (AC Code)

採用 struct + std::sort + Lambda 自訂比較函數實現

#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// 定義活動結構體
struct Activity {
    int id; // 原始編號
    int s;  // 開始時間 (start)
    int f;  // 結束時間 (finish)
};

int main() {
    // 加速 I/O
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;

    vector<Activity> act(n);
    for (int i = 0; i < n; i++) {
        act[i].id = i + 1;
        cin >> act[i].s >> act[i].f;
    }

    // 1. 貪心策略：按結束時間 (f) 升序排序
    sort(act.begin(), act.end(), [](const Activity& a, const Activity& b) {
        return a.f < b.f;
    });

    int count = 0;
    int last_finish = 0; // 記錄上一被選中活動的結束時間

    // 2. 逐個檢查排序後的活動
    for (int i = 0; i < n; i++) {
        // 若當前活動開始時間 >= 上一個選中活動的結束時間，則互不重疊
        if (act[i].s >= last_finish) {
            count++;                // 選中該活動
            last_finish = act[i].f; // 更新最後結束時間
        }
    }

    // 3. 輸出最多可選擇的互不衝突活動個數
    cout << count << "\n";

    return 0;
}
