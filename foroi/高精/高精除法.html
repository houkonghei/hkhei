為什麼需要高精度除法？

普通的 int、long long 能夠存放的位數有限。

如果我們要做非常長的大數字相除，電腦原生變數存不下，就必須模擬人手算長除法。

高精除法會算出商以及餘數：被除數 ÷ 除數 = 商 … 餘數

回憶小學長除法怎麼算

手算長除法的四步驟（重點！跟乘法方向相反）

     2 4
  ------
12 ) 2 8 8
   2 4
  ------
    4 8
    4 8
  ------
     0
  1. 從最高位（左邊）開始，先拿一小段數字和除數比較
  2. 試商：猜這一位可以上幾（0~9），商 × 除數不能比目前這一段還大
  3. 相乘：把商 × 除數的結果寫在下面，對齊位數
  4. 相減：得到剩餘的餘數
  5. 拉下一位：把右邊下一位數字接在餘數後面，繼續重複
高精乘法：從右（個位）往左算；高精除法：從左（最高位）往右算！這是最容易搞混的地方。

程式模擬的重點觀念

  • 高精除法不要倒過來存數字！要保持高位在前（跟我們書寫順序一樣），方便從左邊開始拿數字。
  • 維持一個「目前的餘數」：舊的餘數 ×10，再接下一個新數字，得到當前這一小段。
  • 試商：不斷嘗試可以上幾。
  • 最後要把商前面多餘的 0（前導零）去掉。

完整 C++98 高精度除法（回傳商與餘數）

big_divide.cpp (C++98)
// 高精度大整數除法：被除數 ÷ 除數，得到商、餘數 // 注意！這裡數字【高位在前】存放（與高精乘法相反） #include <iostream> #include <vector> #include <string> #include <algorithm> using namespace std; // 比較兩個大數（高位在前） a >= b ? return true bool isGreaterOrEqual(const vector<int>& a, const vector<int>& b){ if(a.size() != b.size()) return a.size() > b.size(); for(int i=0;i<a.size();i++){ if(a[i]!=b[i]) return a[i] > b[i]; } return true; } // 大數減法 a‑b （保證a>=b，高位在前） vector<int> bigSub(const vector<int>& a,const vector<int>& b){ vector<int> res; int borrow = 0; int i = a.size()-1; int j = b.size()-1; while(i>=0){ int va = a[i] - borrow; int vb = (j>=0)? b[j]:0; borrow = 0; if(va < vb){ va +=10; borrow=1; } res.push_back(va - vb); i--; j--; } reverse(res.begin(),res.end()); while(res.size()>1 && res[0]==0) res.erase(res.begin()); return res; } // 高精度除法，傳入字串；商存在quot，餘數存在rem void bigDivide(string sa, string sb, vector<int>& quot, vector<int>& rem){ quot.clear(); rem.clear(); vector<int> divisor; for(int i=0;i<sb.size();i++) divisor.push_back(sb[i]-'0'); // rem 就是手算時每一步的剩餘數（餘數） for(int idx=0; idx<sa.size(); idx++){ //拉下新的一位數到餘數後面 rem.push_back(sa[idx]-'0'); while(rem.size()>1 && rem[0]==0) rem.erase(rem.begin()); //試商：嘗試可以上幾 int q = 0; while( isGreaterOrEqual(rem, divisor) ){ rem = bigSub(rem, divisor); q++; } quot.push_back(q); } //刪除商的前導零 while(quot.size()>1 && quot[0]==0) quot.erase(quot.begin()); } //輸出高位在前的vector void printVec(const vector<int>& v){ for(int i=0;i<v.size();i++) cout << v[i]; } int main(){ string a,b; cin >> a >> b; if(b == "0"){ cout << "Divide by zero error!" << endl; return -1; } vector<int> quotient, remainder; bigDivide(a,b,quotient,remainder); cout << "商："; printVec(quotient); cout << endl; cout << "餘數："; printVec(remainder); cout << endl; return 0; }

程式碼詳解（入門版）

1. 儲存方向：高位在前！為什麼跟乘法相反？

長除法一開始要先拿最左邊（最高位）一小段出來比較。如果把數字倒過來存，拿前面一小段就很麻煩。所以高精除法直接照原來書寫順序存放數字。這是學生最容易混淆的重點，上課一定要強調和乘法的差異。

2. 模擬手算「拉下一位」

變數 rem 就代表手算時每一步暫時的餘數。每一次迴圈就把被除數的下一位「接」到 rem 的後面，就像我們手算時把數字往下拉下來。

3. 試商怎麼做？（這段比較難）

這份示範程式採用比較直觀的寫法：只要目前的 rem 還大於等於除數，就持續減掉除數，每減一次商就 +1。
（實務上會用乘法預測商加速；但教學用就用重複減法，邏輯跟手算試商一致，學生比較好懂）

4. 最後處理前導零

一開始幾位不夠除的時候，程式會先算出一堆0；這些開頭的0不是真正商的一部分，必須刪掉，不然輸出會出現 0024 這種錯誤。
