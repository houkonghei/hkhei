高精度加法 (BigInt Addition)

演算法與 C++98 實作互動課件

為何需要高精度加法？

超越 C++ 原生型態的極限限制

在 C++ 標準中，極限最大的整數型態為 unsigned long long (64 位元)，其上限約為 $1.8 \times 10^{19}$ (約 19 位數)。 當我們需要處理幾百位甚至幾千位的超大整數（例如：密碼學 RSA 2048 位元、高精度天文計算、Pi 的萬位計算）時，原生型態會發生整數溢位 (Integer Overflow)。

int (32-bit)

~2.14 × 10⁹ (10位)

long long (64-bit)

~9.22 × 10¹⁸ (19位)

高精度數組 (BigInt)

無上限 (受記憶體限制)

高精度加法三大核心步驟

1

字串輸入與倒序儲存

超大整數以 std::string 讀入，並將數字**倒序存入** std::vector<int> 中。

字串 "1234":索引 0 是 '1' (高位)
倒序 (Reverse)
Vector [4, 3, 2, 1]:索引 0 是 4 (個位)
💡 為什麼要倒序？ 因為直式加法從個位 (最低位) 開始計算。倒序存入後，個位對齊在索引 0，若進位向高位擴展時只需 push_back()，不需移動整個數組！
2

逐位加法與進位處理

模擬小學筆算直式加法，從索引 i = 0 開始相加，維持一個進位變數 carry。

sum = A[i] + B[i] + carry;

result[i] = sum % 10; // 當前位數字

carry = sum / 10; // 傳給下一位的進位

⚙️ 邊界處理： 若 $A$ 或 $B$ 的長度較短，超越範圍的位數補 0 參與計算即可。
3

最高位進位與清除前導零

循環結束後，若 carry > 0，需額外將進位放入最高位。最後清除多餘前導零並逆序輸出。

if (carry > 0) C.push_back(carry);

// 去除多餘前導零 (避免 000 結果)

while(C.size() > 1 && C.back() == 0)

    C.pop_back();

C++98 完整高精度加法實作代碼

點擊下方代碼中的高亮區塊，可查看詳細語法解析與歷史設計考量。

// 高精度加法 C++98 標準實作
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>

// 核心高精度加法函數
std::string addBigInt(const std::string& a, const std::string& b) {
    std::vector<int> A, B;


    // 1. 倒序存入 Vector (將字元 '0'-'9' 轉為整數 0-9)
    for (int i = (int)a.length() - 1; i >= 0; --i) {
        A.push_back(a[i] - '0');
    }
    for (int i = (int)b.length() - 1; i >= 0; --i) {
        B.push_back(b[i] - '0');
    }


    std::vector<int> C;
    int carry = 0;
    size_t max_len = A.size() > B.size() ? A.size() : B.size();

    // 2. 逐位相加
    for (size_t i = 0; i < max_len; ++i) {
        int sum = carry;
        if (i < A.size()) sum += A[i];
        if (i < B.size()) sum += B[i];

        C.push_back(sum % 10);
        carry = sum / 10;
    }


    // 3. 處理最高位進位
    if (carry > 0) {
        C.push_back(carry);
    }


    // 4. 清除前導零 (保留至少 1 個位數以應對 "0"+"0")
    while (C.size() > 1 && C.back() == 0) {
        C.pop_back();
    }


    // 5. 倒序轉回 std::string 輸出
    std::string result = "";
    for (int i = (int)C.size() - 1; i >= 0; --i) {
        result.push_back((char)(C[i] + '0'));
    }
    return result;
}

int main() {
    std::string num1 = "9876543210987654321";
    std::string num2 = "1234567890123456789";
    std::cout << num1 << " + " << num2 << " = " 
              << addBigInt(num1, num2) << std::endl;
    return 0;
}

C++98 vs C++11+ 語法差異

  • × 無 auto 關鍵字：必須明確宣告 size_t 或 int。
  • × 無 range-based for (如 for(char c: s))：需使用傳統索引循環。
  • × 無 std::to_string()：字元轉數字使用經典 ASCII 偏移 c - '0'。
  • ✓ 使用 std::vector::push_back() 與 pop_back() 保證 C++98 完全相容。

高精度加法常見陷阱與邊界極限

在競賽或面試中，高精度演算法最容易出錯的細節彙整。

1

最高位進位漏處理 (Final Carry Expansion)

例如計算 999 + 1 = 1000。當主循環 for 結束時，長度為 3 的循環處理完畢，但進位 carry = 1 依然存在。

❌ 忘記處理：輸出 "000"
✅ 正確做法：if (carry > 0) C.push_back(carry);
2

字串與數字 ASCII 偏移量忘記轉換

字元 '0' 的 ASCII 碼是 48，'5' 是 53。若直接將 s[i] 存入數組，存入的是 53 而非整數 5。

❌ 錯誤：A.push_back(s[i]);
✅ 正確：A.push_back(s[i] - '0');
3

長度不相等時的陣列越界 (Out of Bounds)

當相加數字長度不一時（如 100 位數 + 2 位數），長度較短的 Vector 索引會超過範圍。

✅ 邊界安全寫法：
if (i < A.size()) sum += A[i];
if (i < B.size()) sum += B[i];
4

過度清除前導零導致 "0" + "0" 輸出空字串

若輸入為 "00" + "0"，結果數組會是 [0, 0]。若清除前導零時寫成 while(!C.empty() && C.back()==0) C.pop_back();，會把所有 0 全部清空，導致輸出空字串。

✅ 正確做法：保留至少 1 個位數
while (C.size() > 1 && C.back() == 0) C.pop_back();
