為什麼需要高精度乘法？

電腦變數能裝的數字大小是有限的：

  • int 整數：最多大約 10 位數
  • long long 長整數：最多大約 19 位數

如果要計算幾十位、幾百位的超大數字相乘（例如天文數字、密碼學運算），變數裝不下，就必須用「陣列」模擬手算乘法的方法，這就是高精度乘法。

回想小學怎麼算乘法？

豎式乘法

   1 2 3
×   4 5
-------
  6 1 5  ← 用個位 5 去乘 123
4 9 2   ← 用十位 4 去乘 123（要往左錯一位）
-------
5 5 3 5  ← 加起來就是答案
用乘數的「每一位」分別去乘被乘數，然後按照位置錯開相加，最後處理進位。

用程式重現這個過程

第一步：把數字倒過來存

把 "123" 變成 [3, 2, 1]，也就是「個位」放在最前面。這樣從左到右就是個位、十位、百位...計算進位時比較方便。

第二步：相乘對位

被乘數的第 i 位 × 乘數的第 j 位，答案要放在第 i+j 位。

第 i 位 × 第 j 位 → 放到第 i+j 位

第三步：處理進位

每一位如果滿 10，就往左邊進位。

完整 C++98 實現代碼

big_multiply.cpp (C++98 標準)
// 高精度乘法 - C++98 標準實現 // 使用 vector 存儲大整數，低位在前 #include <iostream> #include <vector> #include <string> #include <algorithm> using namespace std; // 字符串轉換為整數數組 (低位在前) vector<int> strToNum(const string& s) { vector<int> num; for (int i = s.size() - 1; i >= 0; --i) { num.push_back(s[i] - '0'); } return num; } // 高精度乘法核心函數 vector<int> multiply(const vector<int>& a, const vector<int>& b) { int n = a.size(); int m = b.size(); vector<int> result(n + m, 0); // 核心：逐位相乘並累加 for (int i = 0; i < n; ++i) { for (int j = 0; j < m; ++j) { result[i + j] += a[i] * b[j]; } } // 處理進位 for (int k = 0; k < n + m; ++k) { if (result[k] >= 10) { result[k + 1] += result[k] / 10; result[k] %= 10; } } // 去除前導零 while (result.size() > 1 && result.back() == 0) { result.pop_back(); } return result; } // 輸出結果 void printNum(const vector<int>& num) { for (int i = num.size() - 1; i >= 0; --i) { cout << num[i]; } cout << endl; } int main() { string sa, sb; cin >> sa >> sb; vector<int> a = strToNum(sa); vector<int> b = strToNum(sb); vector<int> ans = multiply(a, b); printNum(ans); return 0; }

代碼詳解（給入門者）

1. 為什麼要把數字倒過來存？

就像你算豎式時從右邊（個位）開始算一樣。倒過來存之後，陣列的第 0 格就是個位，第 1 格就是十位... 從左到右算過去就好，比較方便。

2. 最關鍵的一行：result[i+j] += a[i] * b[j]

被乘數的第 i 位 × 乘數的第 j 位，答案要放在第 i+j 位。為什麼？因為個位×十位=十位（0+1=1），十位×百位=千位（1+2=3），位數就是相加的關係！

3. 為什麼先全部乘完再處理進位？

因為每一格可以暫時存放大於 10 的數字（int 可以裝很大）。先把所有乘積加起來，最後一次處理進位，程式比較簡單，速度也比較快。

4. C++98 是什麼意思？

這是比較早期的 C++ 標準。這份程式碼刻意不用新語法，確保在比較舊的編譯器（比如學校的教學環境）也能正常執行。
