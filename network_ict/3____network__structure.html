五大常見網絡拓撲 (Network Topologies) 綜合比對

星型拓撲 (Star)

現代 LAN 主流

所有節點獨立連接至中央交換機 (Switch)。若單一終端網線斷裂，其餘設備不受影響。

建置成本:中等 (需要較多網線與 Switch)
容錯能力:高 (單一節點故障不影響全網)
致命弱點:中央 Switch 故障全網癱瘓

總線型拓撲 (Bus)

早期同軸電纜網絡

所有設備共享一根主要幹線 (Trunk Cable)，兩端需裝設終端電阻 (Terminator) 防止信號反射回流。

建置成本:極低 (省線材與設備)
容錯能力:極低 (主幹線中斷即全網中斷)
數據碰撞:高 (廣播網絡易衝突)

環型拓撲 (Ring)

令牌環 (Token Ring)

設備排成封閉環形，數據沿單一方向 (或雙環雙向) 順序傳遞，採用「令牌 (Token)」控制傳送權。

數據碰撞:無碰撞 (令牌傳輸機制)
容錯能力:較低 (單環任一點斷裂即中斷)
傳輸延遲:隨節點增加而遞增

網狀拓撲 (Mesh)

機房/Internet 骨幹

每個節點與多個節點直接相連 (Full Mesh 或 Partial Mesh)。具備冗餘路徑 (Redundant Paths) 與自動重路由。

可靠性/容錯:極高 (具備多重備用路徑)
建置成本:昂貴 (線路公式 n(n-1)/2)
典型應用:電訊商機房、數據中心

樹型拓撲 (Tree)

大型校園/企業網絡

結合星型與總線型的層次化結構（核心層 Core -> 匯聚層 Distribution -> 接入層 Access）。

層次管理:極佳 (便於分區排錯與擴充)
擴展性:極高 (模組化新增子網)
核心依賴:核心路由器故障影響全校

網絡拓撲排錯與實驗闖關

關卡 1: 完成一次星型拓撲數據包傳輸

在「星型拓撲」模式下，成功發送一次從 PC-A 至 PC-B 的 Ping 數據包。

關卡 2: 驗證 Mesh 拓撲的自動重路由 (Redundancy)

切換至「網狀拓撲」，點擊切斷 Router-1 與 Router-2 之間的直接纜線，然後重新發送 Ping 封包，觀察數據包如何經由第三方路由器繞道傳輸。

關卡 3: 模擬並體驗星型拓撲單點故障 (SPOF)

在星型拓撲中雙擊中央 Switch 模擬其故障宕機，此時嘗試發送 Ping，觀察傳輸失敗。
