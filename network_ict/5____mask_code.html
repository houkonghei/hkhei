第一站：通俗理解

IP 地址與子網掩碼，就像「地址與劃線」！

你知道嗎？當你在網絡上發送訊息時，數據就像一封信件。電腦需要依靠 **IP 地址** 找到你是誰、你在哪。

生活中的郵寄地址

陽光大道 (街道名) + 105 號 (門牌號)

郵差先找到 **陽光大道** (網路位置)，再找到 **105 號** (具體哪台電腦)。

電腦網絡中的 IP 地址

192.168.1 . 105

左邊代表 **網絡 ID (Network ID)**，右邊代表 **主機 ID (Host ID)**。

那麼，子網掩碼 (Subnet Mask) 扮演什麼角色？

IP 地址是一串 4 個數字（例如 192.168.1.105），如果沒有規則，電腦怎麼知道「哪一部份是街道名稱（網絡 ID）」，「哪一部份是門牌號碼（主機 ID）」呢？

遮罩是 1 (255)
代表「這一區塊是**網絡地址**」
(就像街道名稱，大家共有)
遮罩是 0
代表「這一區塊是**主機地址**」
(就像門牌號，每台電腦獨有)
劃分邊界 (Subnetting)
就像把一間巨大的學校，用隔板切成小班級，方便管理！
第二站：二進制與邏輯門

電腦如何計算？「按位與 (AND)」運算

電腦不懂十進制，它只看懂 1 和 0。電腦利用 **AND 運算門**，把 IP 地址和子網掩碼疊在一起，得出「網絡地址」。

💡 AND 運算規則：
1 AND 1 = 1 (門打開，通過)
1 AND 0 = 0 (被擋住)
0 AND 1 = 0 (被擋住)
0 AND 0 = 0 (被擋住)
